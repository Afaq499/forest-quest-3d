# Forest Quest 3D

A third-person browser game. Walk a dirt trail through a low-poly forest, collect 10 coins, and stay out of the red thorn bushes. The world is playable immediately. Models exported from [Vi3W](https://app.vi3w.in/) replace the procedural stand-ins when you drop them in `public/models/`.

The trees, rocks, coins, explorer, and shrine you see before that are procedural geometry in this repository. They were not generated by Vi3W.

## Run locally

Requires Node.js 20 or newer.

```bash
npm install
npm run dev
```

Open the URL Vite prints, usually `http://127.0.0.1:5173/`.

## Production build

```bash
npm run build
npm run preview
```

`npm run build` typechecks and writes a static site to `dist/`. `npm run lint` runs oxlint.

## Deploy

Upload the `dist/` folder to any static host (Netlify, Vercel, Cloudflare Pages, or an S3 bucket). For a project site on GitHub Pages, set `base` in `vite.config.ts` to the repository path, then build again.

Put Vi3W files in `public/models/` before building if you want them included in the deployment. Refreshing the dev server is enough while you are iterating locally.

## How to play

Collect all 10 coins. The dirt path leads past every coin. You have 3 hearts. Touching a thorn bush costs one heart and knocks you back. At 0 hearts the run ends. The timer starts when you press Start Game and stops while paused. It is a score, not a fail state.

Finish times earn a rank on the victory screen:

| Time | Hearts | Rank |
| --- | --- | --- |
| 50 seconds or less | all 3 | Grove Legend |
| 55 seconds or less | any | Trailblazer |
| 80 seconds or less | any | Pathfinder |
| anything slower | any | Wanderer |

### Controls

| Input | Action |
| --- | --- |
| W A S D or arrow keys | Move, relative to the camera |
| Space | Jump |
| Esc or P | Pause or resume |
| M | Mute or unmute |
| Enter | Start, resume, or play again |
| R | Restart from the pause or results screen |

On a phone, or a window narrower than 820px, a joystick and a Jump button appear. Sound is synthesized in the browser and the mute choice is remembered.

## Add your Vi3W models

1. Open [app.vi3w.in](https://app.vi3w.in/) and generate one model per row below.
2. Download a `.glb` file. A `.gltf` with its companion files in the same folder also works.
3. Save it in `public/models/` using the exact filename.
4. Refresh the game. The main menu lists which slots loaded.
5. If a model faces backward, lies flat, or is slightly the wrong size, change `yaw`, `pitch`, or `scaleMultiplier` in `src/game/modelConfig.ts`. The game already scales the longest side to `targetSize` and places the bottom on the ground.

Prefer a standard GLB under about 5,000 triangles, Y-up, centered, with no ground plane and no backdrop. A corrupt or missing file is ignored and the procedural stand-in stays on screen.

| File | Replaces | Target size | Prompt to paste into Vi3W |
| --- | --- | --- | --- |
| `public/models/player.glb` | The explorer | 1.7 units tall | A colorful low-poly 3D game character of a young forest explorer, full body, standing in a relaxed idle pose, facing forward. Green tunic, brown belt, brown boots, small brown backpack, red cap. Chunky rounded shapes, cute proportions, single character, centered at the origin, feet on the ground, Y-up, no base, no background. |
| `public/models/tree.glb` | The 18 trees beside the trail | 3.5 units | A single colorful low-poly 3D pine tree for a game, chunky rounded bright green foliage, short smooth brown trunk, stylized and friendly, centered at the origin, trunk base on the ground, Y-up, no ground plane, no background. |
| `public/models/rock.glb` | The rocks beside the trail | 1.25 units | A single colorful low-poly 3D forest rock for a game, rounded chunky gray stone with a patch of green moss, stylized, sitting on the ground, centered at the origin, Y-up, no ground plane, no background. |
| `public/models/coin.glb` | The spinning coins | 0.72 units | A single colorful low-poly 3D gold coin for a game, thick disc standing upright, embossed star on the face, bright yellow metal, centered at the origin, Y-up, no background. If the coin was exported lying flat, set `pitch` to `Math.PI / 2` in `src/game/modelConfig.ts`. |
| `public/models/environment.glb` | The shrine landmark only | 3.3 units | A small colorful low-poly 3D forest shrine for a game, two wooden posts, a curved roof, a hanging lantern, and a few flowers, stylized and friendly, centered at the origin, base on the ground, Y-up, no ground plane, no background. |

`environment.glb` is optional. It does not replace the terrain. Collision sizes stay the same after a swap, so the route around trunks, rocks, and the shrine does not change.

The outer tree ring and the foggy background trees stay procedural on purpose. Copying a detailed tree model dozens of times would make the browser scene much heavier, and the trail trees are the ones the player walks around.

## Project map

- `src/game/store.ts` holds phase, score, hearts, timer, and mute state.
- `src/game/level.ts` places the path, coins, obstacles, and thorns.
- `src/game/modelConfig.ts` is the only file you edit to retune an imported model.
- `src/components/Player.tsx` moves the character, jumps, collides, collects, and takes damage.
- `src/components/AssetModel.tsx` loads a GLB, fits it, and falls back if loading fails.
- Menus and the HUD live in `src/components` and `src/index.css`.
